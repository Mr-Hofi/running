# running

Podklady k maratonu Baroko (42,37 km, +728 m), 5. 9. 2026.

Formatovana stranka: https://mr-hofi.github.io/running/

## Struktura

| Soubor | |
| --- | --- |
| `index.html` | rozcestnik - klicova cisla a odkazy na oba dokumenty |
| `tahak.html` | kratka verze na zavod: kontrolni casy, tri pravidla, km po km, jidlo a piti |
| `plan.html` | cely plan: trat, tempo a TF po fazich, obcerstvovacky, jidlo detailne, snimac, mezicasy |
| `style.css` | spolecne styly pro vsechny stranky |
| `profile_maraton.png` | oficialni profil trati od organizatora |

Tahak i plan maji pripraveny tisk (`@media print` skryva navigaci).

Trenikova data (Garmin exporty, GPX, analyzy) zamerne nejsou v tomto repozitari - obsahuji GPS
souradnice trenikovych tras.
